# Measurements behind writing-prose's rules

The skill body states each rule. This file holds the run that prompted it, for a reader who disputes one.

## Why a citation never names a position

Measured: one document carried 122 line-number citations, four of them already resolving to nothing and the rest untrustworthy the moment nine of the fourteen files they pointed into had text moved.

## Why the cited lines are printed

Measured: one run turned a rule about dead code a change had orphaned into a general principle about which review pass owns a check, and nothing downstream noticed.

## Why the unsourced list needs a wide sweep

Measured: one run drew only on the declared source files and silently dropped an entire section of research grounding that the earlier version of the same document had.
