# status-page measurements

## Rule 3 — a grey notice

On 2026-10-12 in a client repository the operator asked for "a
banner-like thing there under the title that explains the reason for
staleness". Session `f0fad4b7` loaded this skill at 21:43 and built the box
with "a plain grey border and no coloured background", because "the
status-page layout keeps colour on the icons and status words only". At the
time, rule 3 read "Colour on the icon and the status word only" and said
nothing about a notice. The operator answered: "I suspect using such bland
colors is actually wrong."

The research that followed quoted Carbon's inline notification guidance: "When
in doubt, use low-contrast notifications", and Carbon's low-contrast style is a
light tint of the status colour, not grey. Atlassian's section message colours
each message type's background to match the type. The operator accepted the
app's own red failure notice, copied from another page of the app, with "Yes".
