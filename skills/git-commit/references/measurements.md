# Measurements behind git-commit's rules

The skill body states each rule. This file holds the run that prompted it, for a reader who disputes one.

## Why one change of mind is one commit

Measured: a sweep that took the plan document out of four task skills, corrected two measurements in the reference behind them, and added one citation rule to two more, landed as eight commits. Two subjects covered all eight.

## Why each fixup folds as soon as it is committed

Measured: one session's batched autosquash conflicted in five files and was aborted, and the session ended without the fold.

## Why every commit id in the handoff is rewritten after a fold

Measured: one session ran `git commit --fixup` with autosquash, rewrote only the id of the commit it had fixed, and left the three ids behind it stale.

## Why a project's own deploy grant is read before asking

Measured: a build loop halted on the rule above and sat idle for 23 minutes waiting for an answer the operator had already settled.
